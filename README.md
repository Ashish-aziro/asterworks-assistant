# AsterWorks Assistant

Aziro-branded chat front end for the AsterWorks Assistant ApexFlow agentflow.

- Answers questions across Jira, Confluence, GitHub, Slack, Google Drive, Gmail and Salesforce, with cited sources.
- Proposed actions (email, Jira issue, Slack post) are previewed and run only after **Proceed**.

Static site: `index.html`, `app.js`, `site.css`, `aziro.css`. The API endpoint is set at the top of `app.js`.

Built by [Aziro](https://www.aziro.com/).
